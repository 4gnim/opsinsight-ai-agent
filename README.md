# OpsInsight AI Agent

An AI-powered sales and inventory analysis assistant built with
Python, LangGraph, LangChain, Ollama, FastAPI, and SQLite.

## Overview

OpsInsight helps users explore sales and inventory data using
natural-language questions. It combines deterministic SQL tools
with an LLM-based agent.

The application provides:

- Sales summary and revenue metrics
- Top-selling product analysis
- Low-stock product identification
- Natural-language interaction through an AI agent
- A dashboard built with Streamlit
- REST API endpoints for programmatic access

## Features

### Business Report

The `/report` endpoint provides a structured report generated
from database queries. Numerical metrics are calculated by
Python and SQL rather than generated by the LLM.

### AI Agent

The `/ask` endpoint accepts natural-language questions about
sales and inventory. The LangGraph workflow allows the model
to invoke tools to retrieve relevant business data.

### Dashboard

The Streamlit interface displays business metrics, top-selling
products, low-stock products, and an interactive AI chat.

## Local Setup

1. Install Python and Ollama.
2. Pull the configured Ollama model:

   ```bash
   ollama pull qwen3:4b-instruct
   ```

3. Create and activate a virtual environment:

   ```bash
   python -m venv .venv
   ```

   Windows PowerShell:

   ```powershell
   .\.venv\Scripts\Activate.ps1
   ```

4. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

5. Initialize the database and seed the sample data:

   ```bash
   python -m opsinsight.database
   python -m opsinsight.seed_data
   ```

6. Start the API in terminal one:

   ```bash
   uvicorn opsinsight.api:app --reload
   ```

7. Start the dashboard in terminal two:

   ```bash
   streamlit run app.py
   ```

## API Endpoints

| Method | Endpoint  | Purpose                          |
| ------ | --------- | -------------------------------- |
| GET    | `/health` | Check API status                 |
| GET    | `/report` | Retrieve factual business report |
| POST   | `/ask`    | Ask the AI agent a question      |

Interactive API documentation is available at `/docs`
while the FastAPI server is running locally.

## Testing

Run the test suite:

```bash
python -m pytest -q
```

The tests cover database tools, report accuracy, API behavior,
input validation, and error handling.

## Dataset

The project uses synthetic sample data for demonstration.
The current seed dataset contains 10 products and 30 sales
transactions. It is not real company data.

## Limitations

- The available dataset is small and synthetic.
- Profit and margin data are not available.
- Sales targets and historical comparison data are not available.
- LLM responses may still contain inaccurate statements.
  Verify important numerical claims against the factual report.
- The local agent requires Ollama and the configured model.
